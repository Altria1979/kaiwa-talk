# VRoid Avatar A · 虚拟日语伙伴

在本机浏览器里，和 3D 动漫人物练习日语。默认面向初学者，用简短日语交流；中文求助、按需解释、重听与慢放帮助你继续说下去。

也可部署到 **Vercel Services + Turso + private Vercel Blob**，无需自备服务器。云端为个人访问模式，使用密码保护，共享一份历史与设置；部署步骤、所需环境变量和本地数据说明见 [Vercel 部署指南](docs/vercel-deployment.md)。普通本地启动仍使用 SQLite 和磁盘文件。

## 启动

需要 **Node.js 24**、pnpm 9.9，以及支持 WebGL、Web Audio 和 AudioWorklet 的桌面浏览器。默认人物随项目提供，不需要另行下载。

```sh
nvm use
pnpm install --frozen-lockfile
pnpm dev
```

打开 <http://localhost:3000>。启动器同时运行 Next.js 网页和端口 3001 的 Node 服务，两者仅监听 `127.0.0.1`，退出时同时关闭。

如果默认端口已被其他项目占用，可运行 `KOHARU_WEB_PORT=13000 pnpm dev`，网页使用 13000，服务自动使用 13001。生产启动同样支持 `KOHARU_WEB_PORT=13000 pnpm start`，无需按端口重新构建。端口通过命令环境变量设置。

未配置模型服务时，可以查看人物、修改设置、导入模型和管理记忆；聊天入口显示缺少的配置，不生成模拟回复。

## 界面语言

顶部导航（手机端在菜单内）和设置、历史、记忆弹窗的标题栏都可切换「日本語／简体中文／English」。首次访问默认日语，选择通过 `virtualmaid-locale` cookie 保存一年；刷新后首屏直接使用已选语言。浏览器禁止 cookie 时，当前页面仍可切换。

切换立即更新界面、日期、状态和错误提示，保留当前会话、播放和编辑草稿。学习语言、AI 对话、日语解释与学习回顾、用户保存的内容不随界面语言改变。

## 配置百炼

打开「练习设置 → 阿里百炼 API 密钥」，粘贴自己的 API Key，点击「保存密钥」。密钥保存在当前网站的浏览器 localStorage 中，刷新页面后保留，无需重启项目；可显示/隐藏、更新或清除，聊天期间需先结束聊天再修改。北京地域密钥可以直接保存；其他地域或业务空间可展开「接入地址（可选）」，填写百炼控制台提供的 API Host（域名），例如新加坡 `dashscope-intl.aliyuncs.com` 或 `工作空间ID.ap-southeast-1.maas.aliyuncs.com`。密钥与接入地址必须属于同一地域。获取方式见 [百炼官方文档](https://help.aliyun.com/zh/model-studio/get-api-key)。

百炼调用只使用用户在浏览器设置中保存的密钥。未配置或删除密钥后，页面会提示打开练习设置，配置完成前无法开始聊天。服务器不会读取环境变量中的旧百炼密钥作为备用。调用时通过 HTTP 请求头或 WebSocket 开始消息交给后端服务，再由服务转发到百炼官方域名；不会写入 `.env.local`、SQLite、URL 或日志。localStorage 不加密，请仅在自己的可信浏览器使用；清理网站数据会删除密钥，不同浏览器、域名或端口不会共享。保存和刷新状态只检查配置格式，不调用收费模型，也不表示鉴权、模型权限或额度已验证。每次聊天固定使用开始时的凭据，避免另一个页面更换密钥影响正在进行的会话。

模型名称可以通过环境变量调整：按需复制 `.env.example` 为 `.env.local`。已有文件时请直接编辑，不要覆盖；该文件已被 `.gitignore` 排除。本地启动使用内置模型默认值时无需创建环境文件。

```dotenv
BAILIAN_CHAT_MODEL=qwen3.8-flash
BAILIAN_ASR_MODEL=fun-asr-realtime
BAILIAN_TTS_MODEL=qwen3-tts-flash-realtime
```

接入地域与工作空间由网页设置中的 API Host 决定，不能从密钥推断；不同地域模型可用性以实际账户为准。服务从允许的官方域名构造各模型端点：Fun-ASR 使用 `/api-ws/v1/inference`，TTS 使用 `/api-ws/v1/realtime`。

修改模型环境变量后需要重启服务；网页保存密钥立即生效。应用不内置密钥；不要将密钥写入人物设定或使用 `NEXT_PUBLIC_` 前缀。旧的 `BAILIAN_API_KEY`、地域、工作空间和端点环境变量已不再使用，可以从本地及部署环境中删除。Vercel 的数据库、Blob 和网站访问凭据仍需保留。

## 使用

1. 点击「开始聊天」授权麦克风。也可以先打字，再点击「开启语音聊天」。拒绝麦克风授权会降级为文字。
2. 使用日语说话，默认停顿 1.6 秒后由 Fun-ASR 提交发言；设置中可调整等待时间，下次开启语音生效。语音识别固定日语提示，中文求助可使用文字输入。
3. 人物说话或重听时也可以插话。「停止当前回复」取消生成和播放；「静音」关闭麦克风输入，仍可听人物说话。
4. 「中文解释」按需翻译并缓存。「重听」「慢放」使用当前会话完整合成的句子；慢放为 0.8 倍并保持音高。
5. 不知道怎么接话时，回复下方会准备 **3 个推荐回答**，默认附日语、假名读音和中文意思。「照着读」会开启语音或解除静音，选中句子供你看着读；读完停顿后正常识别并继续对话，也可以直接「发送」。跟读时卡片保留，下一轮开始后更新；可随时收起提示。
6. 点击「结束聊天」释放麦克风及音频资源，随后生成话题摘要、三个表达和一个改进建议。建议记忆只有点击保存后才写入。
7. 「记录」查看历史和回顾，「记忆」增删改偏好。先结束当前聊天再切换历史。在历史里发送文字会继续原会话；从已结束记录点击「开始聊天」会新开练习。已生成的推荐回答随消息保存，可展开「回答参考」复习。

重听音频只在当前浏览器会话内保留，结束、断线或刷新后清空。中断的回复可能只留下部分完整句供重听。缓存上限 24 MB，优先移除旧音频；待播音频超过 30 秒时停止播放并提示。

## 替换人物

「设置 → 伙伴的样子 → 更换」选择本地 **VRM 1.0** 文件，最大 30 MB。必须内嵌贴图等资源，拒绝外部资源引用，不支持 VRM 0.x。导入前完整解析，失败时保留原人物；成功后保存在 `data/avatars/`。

项目随附的默认 pixiv 模型固定到特定提交，原始元数据完整保留。来源、哈希和许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

角色区域默认显示腰部以上近景，可使用大小滑杆在全身与胸像之间连续调节，重置按钮恢复默认大小。调整会立即生效，会话期间也可使用；大小保存在当前网站的浏览器本地，刷新后恢复，不同浏览器、域名或端口分别保存。手机端在聊天区上方显示独立角色区域。

口型按实际播放音量驱动嘴巴自然开合，包含静音阈值和开合平滑；流式语音、重听及慢放共用同一逻辑，停止或播放结束后闭嘴，不做逐音素同步。人物有呼吸、眨眼和轻微头部动作；讲话时会降低可能覆盖嘴巴的表情强度，保留口型。

人物下方的「動き／表情／ふれあい」可以直接操作，不需要配置聊天密钥：

- **動き**：挥手、点头、摇头、鞠躬、伸懒腰。每次播放一遍，新动作平滑替换旧动作；挥手和伸懒腰期间镜头临时拉远，结束后恢复原来的大小。
- **表情**：默认「自動」，随当前聊天回复变化；可手动保持自然、开心、放松、难过、生气或惊讶，点击「自動」恢复聊天表情。选择仅保留在当前页面，刷新后恢复自动。
- **ふれあい**：点击头部会微笑歪头，点击身体会短暂惊讶后仰，点击手部会挥手；按钮提供相同操作。临时反应结束后恢复原来的表情，点击不会发送聊天或播放语音。空白处和触摸滚动不触发反应。

鼠标在人物区域移动时，视线和头部会轻微跟随，离开后回正。系统「减少动态效果」偏好会关闭闲置动作及自动追随，手动动作降低幅度。页签可用左右方向键、Home、End 切换，按钮可用键盘激活。模型加载中或失败时操作不可用；自定义模型缺少相应骨骼或表情时，相关按钮会禁用。

自动情绪使用同一次聊天回复首行的内部标记，不额外请求模型。服务端剥离标记后才向界面、语音合成和存储交付正文，独立发送当前轮次的情绪事件；缺失或未知情绪使用自然表情。切换历史、取消、结束或断线会清除自动情绪，过期事件不会覆盖新一轮表情。

人物说话时，嘴巴下方会逐字显示当前句子的字幕，并跟随头部与人物大小调整位置。字幕最多两行，长句自动滚动到最新文字；播完保留 2 秒后淡出，停止或插话后立即清除。实时回复、重听、慢放和示范音频共用字幕。字幕按实际音频播放进度推进，缓冲期间暂停；流式合成尚未完成时先按每秒 6 个可见字符估算，收齐该句音频后按剩余时长校正，不额外等待整句音频。当前是句内近似同步，汉字读音、停顿等可能造成文字与发音的少量偏差；纯文字聊天仍在聊天区显示。

全新部署使用仓库随附的 `public/models/default.vrm`，作者与许可见 [第三方素材声明](THIRD_PARTY_NOTICES.md)。个人曾导入的 Avatar A、黑发角色原型及 Blender 源文件属于本地制作资料，不随代码发布；需要时可在新网站中重新导入。更新名称与显示设置不会替换已选择的模型文件；已有设置中的旧默认名“小春”会显示为 VRoid Avatar A，其他自定义名字和历史内容保留。

## 仓库与发布边界

GitHub 保留应用源码、测试、锁文件、部署配置、必要静态资源和许可说明。`.gitignore` 排除环境文件、私人会话与导入模型、构建结果、依赖目录、IDE/Agent 状态、截图日志及本地建模资料；`.vercelignore` 同样保护部署上传。`.env.example` 只有配置说明和非敏感示例，可以提交。`public/vad/` 由构建脚本从锁定依赖重新生成。

历史设计与验收文档可能引用未发布的本地证据目录；这些目录不是应用运行依赖。云端数据库、Blob 和网站访问凭据仅保存在 Vercel 环境变量中，百炼 Key 由用户在网站设置中填写。

## 架构与数据

```text
浏览器 / Next.js :3000
  ├─ Three.js + three-vrm 人物
  ├─ AudioWorklet → 16 kHz 单声道 PCM16
  ├─ 本地 Silero v6 VAD → 提前插话 / 输入提示
  └─ WebSocket / HTTP → Node :3001
      ├─ Fun-ASR：日语提示 / 云端最终断句
      ├─ Qwen3.8-Flash：流式正文 / 关闭思考
      ├─ TTS：Cherry / 学习语言（日语为 Japanese）/ 24 kHz PCM
      └─ SQLite：设置、记录、完整句播放状态、记忆、回顾
```

| 目录 | 内容 |
| --- | --- |
| `src/app`、`src/components` | 页面、设置、历史、记忆、人物渲染 |
| `src/hooks/use-conversation.ts` | 浏览器会话状态和 WebSocket 协调 |
| `src/lib`、`public/audio` | HTTP API、音频采集、本地 VAD、播放与慢放 |
| `scripts/prepare-vad-assets.mjs`、`public/vad` | 开发/构建前复制本地模型、Worklet 和匹配的 ORT 资源 |
| `server/providers` | Qwen SSE、ASR、TTS 适配器 |
| `server/session.ts` | 轮次编排、插话取消、上下文、回顾 |
| `server/storage.ts` | SQLite 唯一读写入口 |
| `shared/protocol.ts` | 前后端事件与数据类型 |
| `data` | 本地数据库及导入模型，自动创建、不提交 |

对话参数为 `stream: true`、`enable_thinking: false`、`preserve_thinking: false`，仅消费 `delta.content`。回复按完整短句顺序合成；每句采用独立可取消的 TTS 连接，便于释放资源，也会产生句间建连开销。

语音回复只使用本轮学习语言，即使用户打字用中文求助，也不在朗读正文中混入中文解释；需要解释时点击「中文解释」查看文字。纯文字聊天仍可使用辅助语言说明。TTS 按学习语言显式指定语种（日语为 `Japanese`），纯汉字词也按日语合成；英语、韩语、法语、德语和西班牙语同样显式映射，未知自定义语言才使用 `Auto`。每轮固定音色和语种，重听及慢放复用该轮音频。更新后需用新回复验证，旧会话缓存不会重新合成。

为减少误打断，单独的本地人声概率或云端开口通知不会停止回复；代价是自动插话确认会比此前慢一些，仍可点击「停止当前回复」立即停止。最终识别照常提交，短句不会因达不到本地插话门槛而丢失。

每轮分配 `turnId`，插话取消生成、TTS 和播放队列。本地 VAD 在候选开口时捕获目标轮次，本地确认人声且收到非空 ASR 中间文字后发送定向取消；服务端忽略已过期目标。本地与云端开口事件重复到达不会再次取消新轮，已生成的跟读卡片在最终识别提交前保留。只有完整句自然播放结束，浏览器才报告完成。后续语音上下文只把这些句子视为用户已听到，并标记中断；完整生成文本仍能在记录中查看。文字会话以已显示正文作为上下文。

本地 VAD 使用 `@ricky0123/vad-web@0.0.31`、Silero v6 与锁定的 ONNX Runtime 1.22.0，复用麦克风和 AudioContext，模型与 WASM 均从本机页面加载。它提供开口/结束信号，不提交第二份录音、不触发对话；连续 PCM（含静音）仍由 Fun-ASR 统一断句，因此不会串行等待两次 1.6 秒。阈值为 0.8 / 0.5，有效语音累计门槛为 600 ms，采用单线程 WASM。

界面展示增强检测加载状态；检测加载或推理失败时显示“增强检测暂不可用”，继续使用云端识别；降级时也要收到有效中间文字才提前打断，空开口事件不直接停止回复。静音暂停本地检测，结束和断线立即停止麦克风；迟到初始化会独立清理。VAD 判断人声活动，不能纠正口音或保证日语识别准确率，也不能区分你的声音与扬声器回声。

推荐回答使用当前对话模型，在正文生成完成后额外发起一次短请求，与语音合成并行，不等待它才播放主回复。提示遵循学习语言、辅助语言和难度设置；18 秒超时或格式无效时只显示提示暂不可用，聊天继续。未选择的选项不会自动发送、朗读或写入个人记忆，也不会进入后续对话上下文。点击「照着读」不播放示范音频、不进行发音评分，只开启麦克风并保留读音参考。

上下文限量包含人物设定、最近消息、已保存记忆和近期回顾。记忆建议不会自动写入。麦克风音频经本机后端发给阿里识别，对话上下文发给阿里生成，回复文字发给阿里合成。本机不保存原始录音；SQLite 只由 Node 服务读写。

HTTP 写入和 WebSocket 校验网页来源，限制消息与模型大小。服务器不返回密钥、上游响应原文或认证地址，日志不记录音频、对话正文和凭证。同一时间只允许一个页面聊天。

## 构建与检查

```sh
pnpm test
pnpm typecheck
pnpm lint
pnpm build
pnpm start
```

`pnpm test` 使用 Node 24 内置测试、模块模拟与现有 `tsx`，覆盖 TTS 语种协议、流式返回和取消，以及语音/文字回复规则；不调用真实模型或访问用户数据库。真实语音和浏览器检查结果见 [docs/DELIVERY.md](docs/DELIVERY.md)。

麦克风、回声消除、扬声器插话、句间延迟及主观听感仍受浏览器和设备影响，不承诺固定延迟。首次使用可戴耳机减少回声。

## 常见问题

- **Node 版本不对**：执行 `nvm use`。better-sqlite3 是原生模块，切换 Node 大版本后需要重新安装或重建依赖。
- **服务未连接**：确认统一启动器在运行，3000/3001 未被占用，并从 localhost 页面访问。
- **鉴权、权限、模型或额度错误**：在「练习设置」更新密钥和接入地址，确认实际地域、业务空间、模型权限及额度；仅修改环境变量时需要重启。
- **增强检测暂不可用**：语音仍使用 Fun-ASR 识别；确认执行过 `pnpm dev` 或 `pnpm build`，它们会生成 `public/vad/` 本地资源。重新开启语音会重试检测加载。
- **ASR/TTS 异常**：音频状态会清理，保留可用文字对话。不会自动重发上一轮；可手动开启语音或结束后重连。
- **回顾未出现**：可能超时或模型返回格式不完整，聊天记录仍保留，错误会在页面提示。
- **备份**：先停止服务，再备份整个 `data/` 目录。
