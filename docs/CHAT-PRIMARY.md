# 对话为主的交互调整

## 修改前计划

- 将当前会话的完整消息流放回主页面，占据主要宽度；人物移到右侧陪伴区，手机上收为紧凑人物栏。
- 文字输入始终可见，语音开始/结束、静音和停止回复在输入区附近；保留重听、慢放、翻译、历史、记忆和设置。
- AI 推荐回答默认展开，呈现三条建议、读音、释义、照着读和发送；新一轮更新，旧建议保留在对应消息中供回看。
- 实时识别作为消息流末尾的临时用户消息，最终消息接管后不重复；新消息跟随到底部，阅读旧消息时保持位置，并提供“最新消息”入口。
- 学习回顾在聊天结束后直接显示，也保留记录弹窗内查看；不改服务端、存储、协议和人物文件，不增加依赖。
- 用现有 43 项测试锁定基线，再运行 lint、类型检查、测试、构建与模拟浏览器交互/截图验收。截图使用独立固定视口，避免上次软件渲染缩放截图伪影。

## 基线

- 现有 43 项测试全部通过；修改前主页面及样式保存在 `.omx/artifacts/chat-primary/before/`。
- 本次按用户最新反馈调整“对话为主”的信息优先级，替代上次以人物与单轮字幕为主的主页面布局。

## 实现

- `src/components/companion.tsx`：恢复持续可见的完整消息流、常驻输入框、主页面学习回顾；复用消息、翻译、回放、历史与记忆组件。跟随流式新消息，向上翻阅时保持位置，可点击“最新消息”返回底部。
- `src/components/companion.module.css`：主要宽度交给聊天；桌面人物在侧边，手机为顶部紧凑栏。长消息和推荐列表独立滚动；短屏面板按内容增高，允许页面纵向滚动。
- `src/components/reply-suggestions.tsx`：每轮默认展开三条 AI 建议，保留读音、释义、照着读、发送与收起；历史建议留在原回复下。
- 删除仅展示当前轮字幕的主区域、折叠打字入口、紧凑消息变体及相应冗余样式。无新增依赖，无本任务的服务端、协议、存储或人物文件变更。
