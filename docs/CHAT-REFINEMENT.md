# 聊天纸面体验优化

## 修改前计划

用户反馈：当前聊天界面边框层层嵌套，信息密度和操作体验不佳。本次按 `paper-grain-ui` 的留白、文字层级和轻分隔规范改进。

1. 保存修改前样式及相同视口截图，运行既有会话测试和隔离浏览器基线。
2. 移除聊天外框、助手消息卡片和推荐回答卡片，保留纸面材质；用对齐、字号、间距与局部细线组织信息。
3. 推荐回答改为紧凑行列表，保留原有展开、读音、释义、照读、发送及选择状态。
4. 输入框只保留一层边界；键盘聚焦输入框时在容器显示明确焦点，发送按钮保留独立焦点。调整主页面高度与滚动，避免导航遮住标题、输入区被挤出首屏。
5. 桌面聊天为主、人物为辅；手机保持紧凑人物栏，长内容可滚动，短横屏允许纵向滚动。只修改现有样式，保留另一任务正在修改的日文文案。
6. 用现有本机 Playwright/Chrome 做改前改后截图、交互与多视口验证（环境无 agent-browser CLI，不安装新依赖），按 `visual-verdict` 记录每轮观察；运行 lint、类型检查、既有测试和生产构建。

## 边界

不增加依赖，不改会话、语音、持久化、模型和接口。浏览器测试使用隔离模拟，不产生真实模型调用。工作目录没有 Git 元数据，通过修改前副本对照本次样式修改。

## 实现

- `src/components/companion.module.css`：移除聊天外框、助手白色消息框、推荐卡片和次要语音按钮描边；用明朝体正文、分组留白和轻分隔行列表建立层级。保留用户消息的浅色底，让双方身份容易区分。
- 同文件统一输入容器焦点，去掉 textarea 内部轮廓；发送按钮的键盘焦点独立保留。推荐区按可用高度伸缩，长内容内部滚动，输入与控制区保持首屏可达。
- `src/components/paper-navigation.module.css`：导航和主内容左右对齐，适配桌面、平板和手机。
- 保留静态纸纹、完整人物、所有会话交互和并发任务的日文化文案；没有新增业务组件、状态或依赖。

## 已验证

- 修改前 43 项既有测试通过；最终工作区 54 项测试通过（增加的测试来自并行日文化任务）。ESLint、前后端类型检查、生产构建通过。
- 第一轮发现 1000×700 推荐展开时底部控制超出面板约 32px，已修复为推荐内容可伸缩滚动。第二轮 1440×900、390×844、1000×700，包括输入区拉高至 120px、长消息和第三条推荐滚动可达均通过。
- 输入框聚焦时内部 outline 为 none，外容器显示单一 2px 蓝色轮廓；Tab 到发送按钮有独立焦点。
- 生产页面只读烟测：真实已保存人物加载成功、纸纹正常、聊天外框宽度为 0、无横向溢出、主要控件在首屏、无页面异常；未发送消息或修改真实会话/设置。
- 测试证据保存在 `.omx/artifacts/chat-refinement/`，每轮截图与失败记录保留用于比较。初次生产烟测把 Tailwind 的 `border-style: solid` 误判为可见边框，已改为验证实际 `border-width: 0px`，复测通过。
- 最终 21 组浏览器验收通过：流式消息、推荐状态/展开/照读/发送、ASR 临时文本、停止回复、翻译重试、滚动位置、历史、音频、结束回顾、设置和记忆；六视口为 1440×900、1920×1080、1280×720、1000×700、390×844、667×375，无横向溢出或页面异常。完整结果：`.omx/artifacts/chat-refinement/final-2-browser-results.json`。
- `visual-verdict` 独立复核通过（92/100）。移动端滚动边缘的局部消息裁切仍可在后续柔化，不影响消息滚动和操作可达性。最终判定：`.omx/state/chat-refinement/ralph-progress.json`。
- 最新构建与完整本地服务运行于 `http://127.0.0.1:13000`。

## 验证范围

浏览器为本机 Chrome；语音交互使用模拟服务和虚拟麦克风。未验证真实外部模型/麦克风端到端、Safari、Firefox及真实手机硬件。窄屏推荐区需内部滚动，短横屏允许页面纵向滚动。
