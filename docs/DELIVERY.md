## 已实现

- Next.js App Router + React + TypeScript + Tailwind 的本机页面与常驻 Node 服务，统一开发/生产启动，仅监听本机。
- 内置固定版本 pixiv VRM 1.0 模型、本地模型导入、半身镜头、呼吸/眨眼/头部状态动作和实际播放音量口型。
- Qwen3.8-Flash 流式正文对话，关闭思考；日语初学者设定、中文求助、语言和难度设置、按需解释缓存。
- 每轮回复后异步生成三个接话选项，附读音和辅助语言含义；支持照着读、直接发送、收起和历史参考。跟读过程中保留卡片，识别提交或新轮次时清空旧提示；生成失败不阻塞主对话。
- 16 kHz PCM16 AudioWorklet 麦克风采集、Fun-ASR 日语识别与云端断句、本地 Silero v6 VAD 插话提示、实时字幕、按短句 TTS、24 kHz 顺序播放。
- 插话取消、轮次失效过滤、完整句播放确认、静音、停止、文字降级、手动重连、本次会话重听及保持音高的 0.8 倍慢放。
- SQLite 设置、历史、消息和播放状态、记忆增删改、结束回顾和需主动保存的记忆建议。
- 后端环境配置、来源/载荷校验、错误提示、原始录音不落盘、启动说明、素材许可、依赖锁文件。
- 原有 `pelican-bike.html` 保留。

## 实现取舍

直接使用 Three.js 与浏览器音频能力；口型用音量包络驱动。慢放使用 HTMLAudioElement 的保持音高能力；每个短句拥有独立可取消的 TTS 连接。没有另加人物框架、全身动作库、音素对齐服务或专用变速依赖。
