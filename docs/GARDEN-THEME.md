# 花园主题重构

## 后续调整：移除历史与记忆模块

修改前计划：

1. 先运行现有会话、滚动与字幕测试，确认设置、发送和会话回顾已有回归保护。
2. 删除桌面与手机导航中的历史、记忆入口及对应弹窗组件、专属样式和多语言文案；移除回顾中的保存记忆按钮。
3. 删除页面持有的历史/记忆状态与列表请求，保留当前会话、学习回顾、设置和底层会话恢复机制。既有数据库记录与后端存储接口不变，不执行清库。
4. 验证三语导航、设置弹窗与草稿保留、会话发送/结束后回顾，确认前端不再请求历史与记忆列表；运行完整测试、类型检查、Lint、构建和桌面/手机视觉检查。

基线：34 项定向测试通过。没有新增依赖。

完成：移除两组导航入口、HistoryPanel/HistoryMessages/MemoryPanel、回顾中的记忆建议操作、页面列表状态/请求、专属 CSS/图标、客户端列表与记忆管理 API 方法及 26 个专用文案键（三语同步）。保留学习回顾的主题、表达和改进建议，更新设置中的保存说明。后端仍保留已有记录及相关服务能力，本轮不变更后端提示词行为。

改动文件：`src/components/paper-navigation.tsx`、`src/components/companion.tsx`、`src/components/companion.module.css`、`src/components/icon.tsx`、`src/lib/api.ts`、两组 i18n 文案以及 `tests/companion-i18n.test.mjs` / `tests/browser-session.test.mjs`。

验证：596 项完整测试、19 项隔离浏览器检查、Lint、前后端 TypeScript、生产构建、diff 检查通过。新增回归覆盖页面初始化/刷新不加载历史与记忆列表，以及三语学习回顾保留内容且无记忆操作。浏览器覆盖三语桌面/手机导航、设置与焦点、草稿、长对话及结束后回顾；没有模块列表请求或页面运行异常。视觉验收 97/100，无修正项。证据：`/tmp/kaiwa-garden-qa/without-modules-results.json`。真实语音和 Safari 未实测。

## 后续调整：通透对话面板

用户反馈原有整块暖白面板遮挡背景。本轮修改前计划：

1. 复跑现有会话组件与滚动回归；保留发送、语音、记录和设置的既有行为。
2. 将主对话面板改为低不透明度白色玻璃，减少背景模糊、厚边框与阴影；欢迎文字只在局部添加柔和白色衬底。
3. 为主聊天内的实际消息提供局部浅白阅读底，包含释义与建议；保持输入框和操作提示的对比度，避免让整张背景再次泛白。
4. 使用桌面、手机、长对话和短屏截图比较风景透出程度与文字可读性，运行视觉验收和现有检查。修改集中在 `companion.module.css`。

本轮结果：主面板白色不透明度从 91%–96% 降为 14%–34%，模糊从 12px 降为 2px，删除厚内框并减弱阴影。欢迎区使用局部径向柔白衬底；实际消息、识别中间结果与学习回顾各自提供 88% 白色阅读底，历史弹窗不受这些规则影响。

验证：34 项定向基线、595 项完整测试、21 项隔离浏览器检查、Lint、前后端类型检查、生产构建和 diff 检查通过。覆盖正常与短屏、长对话、菜单/弹窗、背景失败和 reduced-motion。脚本与证据在 `/tmp/kaiwa-garden-qa/glass-v1-results.json`；真实语音及 Safari 未实测。

本轮独立视觉验收 94/100：桌面、手机与长对话均通过，无必须修正项。

## 修改前计划

1. 运行既有功能测试作为基线，重点保留文字发送、语音入口、角色控制、设置、记录、记忆和三语切换。只在隔离浏览器内使用模拟数据验证写入操作。
2. 从用户提供的参考图提取蓝天、远山、湖水、花野、树荫与斑驳日光。生成无人物的横向背景，给现有透明 VRM 留出空间，不直接使用带手机控件的截图。
3. 将全屏粗纸纹改为连续花园场景。对话区使用柔和暖白面板保障阅读，角色区透出风景；统一湖蓝、深绿、暖白、淡紫和少量金色细节。
4. 复用现有布局、CSS Module、图标、设置、语音与会话逻辑；调整导航、欢迎区、话题卡、输入区、角色设置及弹窗。降低 Product Hunt 的视觉权重，保留外部入口。
5. 桌面保持对话与人物双栏；手机和短屏保证人物、输入框与弹窗可用。装饰不拦截交互，保留键盘焦点、触摸尺寸和 reduced-motion 支持。
6. 每轮截图与参考图执行 visual-verdict，记录到 `.omx/state/garden-theme/ralph-progress.json`。检查桌面、手机、短横屏及弹窗，运行 lint、前后端类型检查、全部测试和生产构建。

## 范围与取舍

- 不新增依赖，不变更后端协议、用户存储、VRM 文件或音色。
- 背景只作装饰，加载失败时暖白/湖蓝底色仍保障界面可读。
- 去除首页纸纹的全屏重复与高对比推广徽章；不引入主题切换器、复杂粒子系统或自动播放音效。
- 原有纸纹资源和生成回归仍保留，避免为了视觉换肤牵连无关资源。
- 新增主题文案同步日语、中文、英语，尊重用户保存的角色姓名。
